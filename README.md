## 二、原理简述

### 2.1 最小错误率 Bayes 分类器

设类别 $\omega_1$ (Female) 和 $\omega_2$ (Male)，先验概率分别为 $P(\omega_1)$ 和 $P(\omega_2)$。

在正态分布假设下，类条件概率密度为：

$$p(\mathbf{x}|\omega_i) = \frac{1}{(2\pi)^{d/2}|\Sigma_i|^{1/2}} \exp\left[-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma_i^{-1}(\mathbf{x}-\boldsymbol{\mu}_i)\right]$$

**判别函数**（取对数简化）：

$$g_i(\mathbf{x}) = -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_i)^T \Sigma_i^{-1}(\mathbf{x}-\boldsymbol{\mu}_i) - \frac{1}{2}\ln|\Sigma_i| + \ln P(\omega_i)$$

**决策规则**：若 $g_1(\mathbf{x}) > g_2(\mathbf{x})$，则判为 $\omega_1$（女性），否则判为 $\omega_2$（男性）。

### 2.2 参数估计——最大似然法 (MLE)

$$\hat{\boldsymbol{\mu}} = \frac{1}{n}\sum_{k=1}^{n}\mathbf{x}_k$$

$$\hat{\Sigma} = \frac{1}{n}\sum_{k=1}^{n}(\mathbf{x}_k - \hat{\boldsymbol{\mu}})(\mathbf{x}_k - \hat{\boldsymbol{\mu}})^T$$

### 2.3 不相关假设 vs 相关假设

- **不相关假设**：协方差矩阵为对角阵 $\Sigma = \text{diag}(\sigma_1^2, \sigma_2^2)$，特征独立
- **相关假设**：使用完整协方差矩阵，包含特征间协方差信息

### 2.4 最小风险 Bayes 决策

条件风险：$R(\alpha_i|\mathbf{x}) = \sum_j \lambda(\alpha_i, \omega_j) P(\omega_j|\mathbf{x})$

选择使条件风险最小的决策 $\alpha_i$。

## 四、实验结果与分析

### 4.1 实验一：单特征 Bayes 分类

#### 身高特征

| 先验概率 (F/M) | test1 错误率 | test2 错误率 |
|:--------------:|:----------:|:----------:|
| 0.50 / 0.50 | **5.71%** (2/35) | **9.00%** (27/300) |
| 0.75 / 0.25 | 11.43% (4/35) | 22.00% (66/300) |
| 0.90 / 0.10 | 20.00% (7/35) | 49.00% (147/300) |
| 0.25 / 0.75 | 8.57% (3/35) | 6.67% (20/300) |
| 0.10 / 0.90 | 11.43% (4/35) | 5.67% (17/300) |

#### 体重特征

| 先验概率 (F/M) | test1 错误率 | test2 错误率 |
|:--------------:|:----------:|:----------:|
| 0.50 / 0.50 | **5.71%** (2/35) | **14.67%** (44/300) |
| 0.75 / 0.25 | 11.43% (4/35) | 26.00% (78/300) |
| 0.90 / 0.10 | 28.57% (10/35) | 44.33% (133/300) |
| 0.25 / 0.75 | 5.71% (2/35) | 11.00% (33/300) |
| 0.10 / 0.90 | 17.14% (6/35) | 8.33% (25/300) |

**分析**：
- 等先验概率下，身高特征的错误率（9.00%）低于体重特征（14.67%），说明**身高对性别的区分能力更强**。
- 先验概率对决策有显著影响：偏向女性先验时，更多样本被分为女性，导致女性被错判率降低但男性错判率升高。

### 4.2 实验二：双特征 Bayes 分类

#### 不相关假设（对角协方差）

| 先验概率 (F/M) | test1 错误率 | test2 错误率 |
|:--------------:|:----------:|:----------:|
| 0.50 / 0.50 | **2.86%** (1/35) | **9.67%** (29/300) |
| 0.75 / 0.25 | 2.86% (1/35) | 15.00% (45/300) |
| 0.90 / 0.10 | 8.57% (3/35) | 19.33% (58/300) |

#### 相关假设（完整协方差）

| 先验概率 (F/M) | test1 错误率 | test2 错误率 |
|:--------------:|:----------:|:----------:|
| 0.50 / 0.50 | **2.86%** (1/35) | **10.67%** (32/300) |
| 0.75 / 0.25 | 14.29% (5/35) | 20.00% (60/300) |
| 0.90 / 0.10 | 20.00% (7/35) | 32.67% (98/300) |

**分析**：
- 双特征分类显著优于单特征：test2 上从 9.00%（身高）降至 9.67%（双特征），test1 上从 5.71% 降至 2.86%。
- 不相关假设与相关假设结果接近，因为男女各自的相关系数（0.42, 0.65）属于中等水平。
- 有趣的是，不相关假设在部分场景下错误率略低于相关假设，这是因为 MLE 估计的协方差矩阵在小样本下可能不准确。

### 4.3 实验三：最小风险 Bayes 决策

对称损失 $\lambda = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}$（等同最小错误率）：

| 方法 | test1 错误率 | test2 错误率 |
|------|:----------:|:----------:|
| 1D-身高 | 5.71% | 9.00% |
| 1D-体重 | 5.71% | 14.67% |
| **2D-完整协方差** | **2.86%** | **10.67%** |

当女生→男风险=5 时（$\lambda = \begin{bmatrix} 0 & 5 \\ 1 & 0 \end{bmatrix}$）：

| 方法 | test1 错误率 | test2 错误率 |
|------|:----------:|:----------:|
| 1D-身高 | 8.57% | 5.00% |
| 1D-体重 | 14.29% | 9.33% |
| **2D-完整协方差** | **8.57%** | **4.67%** |

**分析**：提高女生→男错判代价后，分类器倾向判为女性，test2 错误率从 10.67% 降至 4.67%（但这是以更多男性被错判为女性为代价）。

## 六、体会与总结

1. **特征选择很重要**：身高比体重对性别区分度更高，但双特征联合使用效果最优，符合"更多有效信息→更好分类"的直觉。

2. **先验概率是双刃剑**：先验概率反映了我们对类别的先验信念。当实际分布与先验一致时能提高准确率；不一致时反而造成偏差。实际应用中需谨慎设定。

3. **相关 vs 不相关**：理论上完整协方差更准确，但需要估计更多参数（d(d+1)/2 个），在小样本下可能过拟合。本实验中两者差距不大，说明特征间相关性尚不足以使模型产生质的差异。

4. **最小风险决策的价值**：通过引入损失函数，我们可以根据实际问题的代价结构调整分类器行为（如宁可误判为女性也不漏掉女性），这在医学诊断等场景中非常重要。

5. **正态假设的合理性**：身高和体重的分布近似正态，这一假设基本合理，但从直方图来看存在一定偏差，未来可尝试非参数方法。
